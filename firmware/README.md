# ESP32-C3 / ST7789

Проект для **ESP-IDF 5.5**, версия Display Studio 0.4.1. В локальном комплекте четыре объединённых BIN-файла для смещений Y=0/Y=80 и RGB/BGR; в приложении есть встроенный прошивальщик. Добавлен PWM подсветки на GPIO5. Образы содержат загрузчик, таблицу разделов и приложение и записываются с адреса 0x0. Нужны ESP32-C3 ревизии 0.3+ и флеш 4 МиБ. Аппаратная часть ещё не проверялась: платы и дисплея сейчас нет. Проверки на ПК и успешная сборка не заменяют проверку USB, SPI, питания и панели на устройстве.

## Структура

- `portable/md_protocol.*` — пакетизация и CRC, без зависимостей ESP-IDF.
- `portable/md_device.*` — последовательность команд, проверка покрытия и вызовы вывода блока.
- `main/main.cpp` — USB, ST7789, ожидание DMA и резервные часы.

Используются один буфер пакета около 7,6 КиБ, один DMA-буфер 7,5 КиБ, USB RX 16 КиБ и служебные структуры. Полный кадр RGB565 на 112,5 КиБ в прошивке не хранится. Полный массив есть только в эмуляторе/тестах, где он заменяет внутреннюю RAM контроллера дисплея. DMA-буфер не переиспользуется до callback завершения передачи.

## Сборка

В настроенном окружении ESP-IDF:

```text
cd firmware
idf.py set-target esp32c3
idf.py menuconfig
idf.py build
```

Пункт **Mini Display ST7789** задаёт контакты, частоту SPI, смещения, RGB/BGR, инверсию и ориентацию. Начальные значения — заготовка конфигурации для будущего подключения:

| Сигнал | Начальное значение |
|---|---:|
| SCLK | GPIO4 |
| MOSI | GPIO6 |
| CS | GPIO7, либо -1 для панели без CS |
| DC | GPIO1 |
| RESET | GPIO3, либо -1 |
| BL / PWM | GPIO5, активный высокий уровень, LEDC 20 кГц / 10 бит |
| SPI | 20 МГц |

Это **не подтверждённая схема подключения конкретного модуля**. Перед подключением нужно сверить маркировку и питание дисплея, способ питания подсветки и допустимый ток, а также распиновку SuperMini. Пины разных сигналов должны различаться. GPIO18/19 оставлены встроенному USB; GPIO2/8/9 связаны с загрузочными режимами ESP32-C3 и не используются начальными значениями.

GPIO5 соединяется напрямую с BL **только если BL — логический PWM-вход 3,3 В**. Если BL питает светодиоды, GPIO5 подключается к PWM-входу внешнего драйвера подсветки с подходящими напряжением/током; питание светодиодов не проходит через GPIO. Земля общая. BL нельзя одновременно соединять с GPIO5 и 3V3. Подробнее — в инструкции пользователя. Внешний JTAG GPIO4–7 при этой распиновке не используется; встроенный USB Serial/JTAG остаётся доступным.

Параметры `MD_PIN_BL`, `MD_BL_ACTIVE_HIGH` и `MD_BL_DEFAULT_PERCENT` задаются в menuconfig. Пин -1 отключает регулировку. Проверка при компиляции запрещает совпадение BL с другими сигналами и загрузочными GPIO. До запуска панели PWM выключен; после первого кадра применяется уровень из NVS, при отсутствии сохранённого значения — 80%. Команда MDP1 меняет PWM и получает ACK; NVS обновляется через 2 секунды без изменений, при сбое повтор через 5 секунд. Неизменный уровень повторно во флеш не пишется. Яркость сохраняется при переходе к резервным часам. NVS с ошибкой не стирается автоматически и не блокирует работу USB/подсветки.

Расширенный Hello `[1]` возвращает флаг поддержки подсветки, пустой Hello совместим с приложением 0.4.0. Изменение яркости не меняет RGB565 и не вмешивается в SPI DMA. API сверено с [ESP-IDF LEDC](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32c3/api-reference/peripherals/ledc.html).

Приложение требует встроенный USB Serial/JTAG ESP32-C3; внешний UART-мост этой прошивкой не обслуживается. Отладочная консоль направлена в UART, чтобы сообщения ESP-IDF не перемешивались с USB-пакетами. Не открывайте USB-порт одновременно в приложении и терминале/мониторе.

Когда появится плата, после проверки конфигурации:

```text
idf.py -p COMx flash
```

Затем закройте монитор порта и выберите нужный COM в приложении. После включения до синхронизации видны оранжевые прочерки; через 5 секунд без программы — резервные часы HH:mm. После полного отключения питания время теряется.

Драйвер и порядок инициализации сверены с [ESP-IDF SPI LCD](https://docs.espressif.com/projects/esp-idf/en/v5.5/esp32c3/api-reference/peripherals/lcd/spi_lcd.html), API USB — с [заголовком ESP-IDF 5.5](https://github.com/espressif/esp-idf/blob/v5.5/components/esp_driver_usb_serial_jtag/include/driver/usb_serial_jtag.h). Конкретному модулю ST7789 могут понадобиться другие смещения, инверсия, RGB/BGR и дополнительные команды инициализации.

## Что ещё проверить с железом

Питание и подсветка, распознавание USB Windows, цвета/ориентация/границы, реальная скорость полных и частичных кадров, повторное подключение, сон Windows и суточный прогон. Полная сборка ESP-IDF и структура BIN проверены. Локальные ресурсы, LittleFS, палитры, RLE и GIF пока отсутствуют; используется стандартная таблица с одним приложением и служебными разделами. Инструкция конечного пользователя — [docs/user-guide.md](../docs/user-guide.md).
