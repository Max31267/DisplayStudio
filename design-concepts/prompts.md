## Финальные промпты

### 01 — Тёмная студия

Use case: ui-mockup. Create a polished high-fidelity raster design concept of the Windows desktop app 'Display Studio', an editor for a small PC-connected 240x240 display. One complete front-facing application window, landscape 1536x1024 composition, nearly fills the image, readable Russian labels, clean vector-like typography, crisp smooth text, realistic implementable desktop UI. This is an app UI concept, not a website or a physical device photo. Retain these actual functions: editable pages, page durations, layer list, draggable text/clock/date/seconds bar on a square canvas, per-layer typography and colors, background color palette, emulator connection, undo and redo, open and save. The central square display layout must show '13:45' in large smooth white digits, a mint accent, 'МОЙ ДИСПЛЕЙ', 'среда, 28 октября' on a dark deep-teal background. UI labels include 'Редактор', 'Предпросмотр', 'Страницы', 'Слои', 'Свойства', 'Часы', 'Мой экран', 'Тест цветов', 'Время показа', '15 с', 'Цвет фона', 'Размер шрифта', 'Подключить', 'Открыть', 'Сохранить'. Limit copy to necessary short labels; keep Cyrillic accurate. Show no active dialogs, no code, no charts, no extra invented product features, no perspective tilt, no photography, no watermark, no overwhelming glow.
Design direction 01: 'Тёмная студия'. A refined professional creative tool: warm near-black #111218, charcoal panels #1A1D27, subtle lavender #A79BFF as the primary accent, muted gray text, elegant thin borders, precise consistent spacing and small rounded corners. Calm premium mood, excellent contrast, no neon or excessive glass. Upper toolbar with restrained Display Studio logo, undo/redo, Open and lavender Save button, a compact emulator connection status. Three-pane layout: narrow left sidebar with three page cards and duration chips, a separate layers list below; large uncluttered center workspace with the square display canvas and small editor/preview segmented tabs; right inspector with page name, timing, X/Y fields, font size and color swatches in nicely grouped compact sections. Selected page and selected layer have quiet purple emphasis. Canvas text is especially smooth and sharp, no pixel blocks and no coordinate grid over the clock. Small elegant bottom status line. Add a tasteful small outside-artboard concept label at the very top: '01 / ТЁМНАЯ СТУДИЯ'. Make this feel like a mature, spacious, carefully designed desktop creative application.
